# 💰 Expense Tracker System

A Python-based expense tracking application built with **Streamlit, SQLite, and Pandas**. The application allows users to record daily expenses, manage expense history, generate monthly reports, and analyze spending patterns through charts and summaries.

## 🚀 Features

- ➕ Add daily expenses
- 💾 Store expenses in SQLite database
- 🏠 Dashboard with overall spending summary
- 📋 View expense history
- 🔽 Display most recent expenses first
- 🗑️ Delete expenses
- 📅 Generate monthly expense reports
- 📊 View category-wise spending
- 📈 Analyze monthly spending trends
- 💰 Display total spending, transaction count, and average expense
- ⚠️ Handle empty expense records
- 🔄 Automatically update reports and dashboard after adding or deleting expenses
- 💵 Store monetary values in paise for accurate database storage

## 🛠️ Technologies Used

- **Python**
- **Streamlit** – Web-based user interface
- **SQLite** – Database storage
- **Pandas** – Data processing and analysis
